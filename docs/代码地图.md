## 数据结构约定

所有平台解析器最终都产出 `TweetFetcher.Result`：

```java
class Result {
    String id;          // 作品 ID（去重 key 用）
    String title;       // 标题/作者，用于文件名
    String thumb;       // 封面地址
    List<Media> items;  // 可选画质
}
class Media {
    String url;         // 视频直链
    String label;       // "1080P · 带声音"
    String thumb;       // 该档封面
    String audioUrl;    // 非空 = 需要合成
    int w, h;           // 用于判断竖/横屏
}
```

拿不到音轨时 `audioUrl` 留空，走单文件；**不要**给一个只有画面的 dash 链接。
